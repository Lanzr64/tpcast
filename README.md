# Teleport Cast

Teleport Cast 是一个面向 Minecraft 1.19.2、基于 Minecraft Forge 43.4.0 的传送命令模组。它提供家、重生点、死亡返回和玩家间传送，并用可配置的“过载”机制限制连续传送。

## 版本要求

- Minecraft：1.19.2
- Minecraft Forge：43.4.0（Forge 43 系列）
- Java：17

## 功能

- 设置并传送到个人家，可跨维度使用。
- 传送到主世界重生点。
- 死亡后返回死亡位置；使用一次后记录会被清除。
- 通过请求和接受机制进行玩家间传送。
- 传送会增加过载等级；过载冷却、传送消耗和熔断惩罚均可在服务器配置中调整。

## 命令

以下命令由服务器执行，玩家需要在游戏中使用。除特别标注外，命令没有额外的 OP 权限要求。

| 命令 | 说明 |
| --- | --- |
| `/sethome` | 将当前位置设为个人家。 |
| `/home` | 传送回个人家；尚未设置家时会提示无家可归。 |
| `/spawn` | 传送到主世界的世界重生点。 |
| `/back` | 返回最近一次死亡时的位置；成功使用后记录会被清除。 |
| `/tpa <玩家>` | 请求传送到指定玩家身边；对方使用 `/tpy` 接受，使用 `/tpn` 拒绝。接受后由请求者传送。 |
| `/tpahere <玩家>` | 请求指定玩家传送到你身边；对方使用 `/tpy` 接受。 |
| `/tpy` | 接受发给自己的传送请求。 |
| `/tpn` | 拒绝发给自己的 `/tpa` 请求。 |
| `/self-check` | 查看当前过载状态；熔断时显示恢复倒计时。 |
| `/cast-assist <玩家>` | 为另一名玩家施加祈福效果，并调整双方过载。 |
| `/resetCoolDown <玩家>` | 清除指定玩家的过载。需要 OP 权限等级 4。 |
| `/c-tp <区块X> <区块Z>` | 按区块坐标传送，保留当前高度。需要 OP 权限等级 4；输入坐标会乘以 16 转成方块坐标。 |

### 附带命令

这些命令属于项目内的附加功能：

| 命令 | 说明 |
| --- | --- |
| `/hat` | 将头盔栏物品与手上的物品交换。 |
| `/tyjtyj` | 消耗与回家相同的过载，并掉落一份熟鸡肉。 |
| `/cast-off` | 丢弃玩家的全部物品。 |

## 过载与服务器配置

首次启动服务器后，配置文件会生成在当前世界目录的 `serverconfig/tpcast-server.toml`。更改后按 Forge 的配置加载方式生效。

| 配置项 | 默认值 | 说明 |
| --- | ---: | --- |
| `max level` | `3` | 熔断前允许积累的最大过载等级。 |
| `cooldown per level` | `180` 秒 | 每一级过载的恢复时间。 |
| `back cost` | `0.5` | `/back` 的过载消耗。 |
| `home cost` | `1.0` | `/home` 的过载消耗。 |
| `tpa cost` | `1.5` | 玩家间传送的过载消耗。 |
| `spawn cost` | `1.0` | `/spawn` 的过载消耗。 |
| `punishment` | `2.0` | 熔断时额外增加的过载等级。 |

过载等级会随时间恢复。传送消耗使累计过载超过上限时会触发熔断，并追加惩罚过载；熔断期间不能使用受过载限制的传送命令。

## 安装

将构建好的 `tpcast-0.1.0.jar` 放入服务器的 `mods` 目录，然后启动 Forge 1.19.2 服务器。模组的功能由服务器提供，客户端无需安装本模组。

## 从源码构建

需要安装 Java 17。Windows 可在项目目录运行：

```powershell
.\gradlew.bat build
```

其他平台可运行：

```bash
./gradlew build
```

构建产物位于 `build/libs/`。如需生成 IDE 运行配置，可运行 `genIntellijRuns` 或 `genEclipseRuns` Gradle 任务。
